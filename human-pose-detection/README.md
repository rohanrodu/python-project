# 🧍 Human Pose Detection using Python

This project uses **computer vision** and **machine learning** to detect human body poses in real-time through a webcam feed or video input. It's built using **Python**, leveraging **MediaPipe** and **OpenCV** for accurate and efficient landmark detection.

> 🔄 *Note: Future updates may include new features, performance enhancements, and GUI improvements.*

---

## 📌 Features

- 📹 Real-time human pose detection using webcam or video files
- 🔍 Detects and tracks key body landmarks (shoulders, elbows, knees, etc.)
- 📈 Calculates joint angles for fitness or motion analysis
- 🖼️ Visual overlay on detected keypoints and skeleton
- 🧠 Built with **MediaPipe Pose** and **OpenCV**
- 💾 Option to save output in csv file

---

## 🛠 Tech Stack

- **Python 3.x**
- [MediaPipe](https://google.github.io/mediapipe/) (for pose estimation)
- **OpenCV** (for video input/output and drawing)
- **Tkinter** for GUI enhancements  PIL, ImageTk
- Libraries used -  threading, time, math, os, csv,

# 🧑‍💼 Face Recognition Attendance Tracker

A smart and efficient **Attendance Tracker** built with Python that uses **facial recognition** to automatically log attendance. Designed for classrooms, offices, or any environment where fast, contactless check-ins are needed.

> 🔄 *Note: Updates and new features may be added in the future.*

---

## 📌 Features

- 🎯 Face detection and recognition using **OpenCV** and **face_recognition**
- 🕒 Logs attendance with **timestamp** and **date**
- 🗃️ Attendance saved automatically to a CSV file
- 🖼️ Optional custom logo or UI overlay
- 🧑‍💻 Easy to use: just add reference photos and run the script

---

## 🛠 Tech Stack

- Python 3.x
- OpenCV
- face_recognition
- NumPy
- Pandas
- Tkinter (optional for UI)
- PIL (for image/logo support)

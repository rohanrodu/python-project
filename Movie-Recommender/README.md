# 🎬 Movie Recommender

A beginner-friendly Python application that suggests similar movies based on the plot overview you input or select. Utilizing **TF-IDF vectorization** and **cosine similarity**, this simple tool provides relevant movie recommendations through a clean and intuitive **Tkinter GUI**.

> 🔄 *Note: Future enhancements may include additional filters, personalized recommendations, and richer UI.*

---

## 📌 Features

- 🔍 Search or select movies by title  
- 🎯 Get top-N similar movie recommendations based on plot descriptions  
- 🖥️ Simple graphical interface built with **Tkinter**  
- 🔢 Adjustable number of recommendations via slider  
- 📄 Utilizes the popular **TMDb 5000 Movies** dataset  
- 🔧 Easy to understand and customize — perfect for beginners  

---

## 🛠 Tech Stack

- Python 3.x  
- Pandas (for data handling)  
- scikit-learn (for TF-IDF and similarity calculations)  
- Tkinter (for GUI)
